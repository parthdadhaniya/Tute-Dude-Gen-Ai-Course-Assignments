# Assignment 9: NumPy (Mathematical & Statistical Operations)

This folder contains my Python solutions for Assignment 9 using NumPy. It covers array creation, basic math operations, mathematical formulas, 2D aggregations, statistical operations, percentiles, and a weekly sales analysis task.

## Task Details

* **task1.py (Creating NumPy Arrays)**
  Creates a 1D array (1 to 10), a 3x3 2D array (1 to 9), and an array from a list, then prints their shape and data type.

* **task2.py (Important Mathematical Operations)**
  Performs addition, subtraction, multiplication, division, and power operations on two arrays, including `np.add()` and `np.subtract()`.

* **task3.py (Important NumPy Mathematical Formulas)**
  Calculates square root, exponential, natural log, total sum, and cumulative sum using NumPy functions.

* **task4.py (Aggregation Operations)**
  Finds the row-wise sum, column-wise sum, min, max, and overall mean for a 3x3 2D array.

* **task5.py (Statistical Operations)**
  Calculates mean, median, variance, standard deviation, min, max, and range on student marks.

* **task6.py (Percentiles & Sorting)**
  Sorts the marks array, finds the 25th, 50th, and 75th percentiles, and counts students scoring above average.

* **task7.py (Mini Use Case: Sales Analysis)**
  Finds total weekly sales, average daily sales, highest/lowest sales day, standard deviation, and days with above-average sales.

## How to Run

You can run all tasks at once or run each file individually:

```bash
python main.py
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
python task6.py
python task7.py
```
