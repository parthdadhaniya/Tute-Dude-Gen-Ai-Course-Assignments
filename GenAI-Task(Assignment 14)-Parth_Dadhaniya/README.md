# Assignment 14: Feature Engineering, Encoding, Scaling & Pipelines

This project covers feature engineering, one-hot encoding, scaling, and scikit-learn pipelines.

## Files Included

- **`employee_data.csv`**: Dataset with numerical, categorical, and date columns.
- **`task1_new_features.py`**: Creating new features.
- **`task2_date_features.py`**: Extracting year, month, and day.
- **`task3_one_hot_encoding.py`**: One-hot encoding with `pd.get_dummies`.
- **`task4_column_transformer.py`**: Using `ColumnTransformer`.
- **`task5_standard_scaler.py`**: Standardizing with `StandardScaler`.
- **`task6_minmax_scaler.py`**: Normalizing with `MinMaxScaler`.
- **`task7_preprocessor_pipeline.py`**: Building preprocessing pipeline.
- **`task8_full_pipeline.py`**: Full pipeline with LinearRegression.
- **`task9_pipeline_concepts.py`**: Conceptual answers on pipelines.
- **`main.py`**: Runs all tasks.
- **`assignment14.ipynb`**: Complete Jupyter Notebook.

## How to Run

Run all tasks:
```bash
python main.py
```

Or run any task file:
```bash
python task1_new_features.py
python task2_date_features.py
python task3_one_hot_encoding.py
python task4_column_transformer.py
python task5_standard_scaler.py
python task6_minmax_scaler.py
python task7_preprocessor_pipeline.py
python task8_full_pipeline.py
python task9_pipeline_concepts.py
```
