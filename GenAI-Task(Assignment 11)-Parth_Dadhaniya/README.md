# Assignment 11: Matplotlib (Core Plot Types & Visualization)

This folder contains Python scripts and a Jupyter Notebook for Assignment 11 on Matplotlib. It covers basic plotting techniques using Matplotlib directly without Seaborn or Pandas plotting shortcuts.

## Task Details

* **task1.py (Line Plot - Sales Trend)**
  Creates a line plot showing monthly sales trend from sales_data.csv with title and axis labels.

* **task2.py (Scatter Plot)**
  Creates a scatter plot showing relationship between advertising budget and sales with title and labels.

* **task3.py (Bar Plot - Vertical & Horizontal)**
  Creates both a vertical and a horizontal bar chart showing category-wise sales.

* **task4.py (Multiple Bar Plot)**
  Creates a grouped multiple bar chart comparing sales across 2023 and 2024 with proper bar width, alignment, and legend.

* **task5.py (Stacked Bar Chart)**
  Creates a stacked bar chart displaying offline and online sales by product category with legend.

* **task6.py (Histogram - Marks Distribution)**
  Plots a histogram of student marks distribution using 5 bins and axis labels.

* **task7.py (Pie Chart - Market Share)**
  Creates a pie chart showing category market share with percentage values (`autopct='%1.1f%%'`) and title.

* **main.py & assignment11.ipynb**
  Contains all 7 tasks clearly separated in a single Python file and Jupyter Notebook.

## How to Run

Run all tasks together:

```bash
python main.py
```

Or run each file individually:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
python task6.py
python task7.py
```
