[00:00] Hi everyone, welcome to this introduction to Large Language Models. Today we will break down what an LLM actually is, how it is trained, and where this technology is heading.
[00:45] To start, what is an LLM? At its core, a large language model is just two files on your computer. One file contains the parameters or weights of a deep neural network, and the second file is a small piece of code, maybe in C or Python, that executes the neural network architecture.
[01:30] For example, Meta released the Llama 2 70B model. The parameters file is approximately 140 gigabytes because it holds 70 billion parameters, with each weight stored as a 2-byte float. The run script to evaluate the network can be written in around 500 lines of pure C.
[02:45] How do we get these parameters? The first major step is Pre-training. We scrape a massive slice of the public internet: web pages, Wikipedia articles, books, code repositories, and news. For Llama 2, this was around 10 terabytes of text, which translates to roughly 2 trillion tokens or words.
[04:00] Pre-training requires enormous computational resources. Meta used thousands of GPUs running continuously for months, costing several millions of dollars. The training objective is simple: predict the next token given all previous tokens in a sequence. By predicting the next word repeatedly across trillions of tokens, the network is forced to learn grammar, facts, reasoning, and world knowledge.
[05:30] However, a pre-trained base model is not a chatbot. It is a document completer. If you ask a base model "What is the capital of France?", it might respond with "What is the capital of Germany?" because it thinks it is completing an exam paper.
[06:45] To turn a base model into a helpful assistant, we perform Fine-Tuning, specifically Supervised Fine-Tuning (SFT) and Reinforcement Learning from Human Feedback (RLHF). Human labelers write thousands of high-quality conversational prompts and ideal assistant answers. We train the network on these question-and-answer pairs so it learns to follow instructions politely and accurately.
[08:15] Let us talk about LLM limitations and hallucinations. An LLM does not have a real-time internet connection built into its weights; its knowledge is frozen at the cutoff date of pre-training. When an LLM does not know a fact, it may hallucinate and generate plausible-sounding but factually incorrect statements.
[09:40] To mitigate hallucinations, modern architectures use Retrieval-Augmented Generation (RAG) and tool use. When a user asks a question, the system can search a vector database or Google, retrieve fresh factual snippets, and paste them into the LLM context window.
[11:00] What is the context window? The context window is the working memory of the language model. Everything the model reads and outputs must fit within this window, which can range from 4,000 tokens up to 128,000 tokens in newer models. If information falls outside the context window, the model cannot access it.
[12:30] Another interesting topic is System 1 versus System 2 thinking. Daniel Kahneman described System 1 as fast, instinctive thinking and System 2 as slow, deliberate reasoning. Right now, LLMs behave primarily like System 1: each token takes roughly the same amount of computation to generate. Future AI research is focused on System 2 architectures where models can think, backtrack, search through trees of possible thoughts, and verify answers before outputting them.
[14:15] Finally, let us discuss LLM security challenges. The primary vulnerability is prompt injection, where an attacker embeds hidden adversarial instructions into data that the model reads, tricking it into ignoring system rules or leaking private information. Other risks include jailbreaks and training data poisoning.
[16:00] In summary: LLMs are trained in two stages (pre-training on internet data, followed by fine-tuning with human feedback), their working memory is bounded by the context window, and techniques like RAG and tool use allow them to access fresh, reliable facts. Thank you for watching!
