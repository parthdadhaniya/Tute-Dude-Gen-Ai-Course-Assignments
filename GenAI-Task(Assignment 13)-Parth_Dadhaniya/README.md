# Assignment 13: Data Gathering, Preprocessing & EDA

This project covers data gathering, preprocessing, and EDA for Assignment 13.

## Files Included

- **`kaggle_dataset.csv`**: Employee dataset from Kaggle.
- **`products.json`**: Product JSON data.
- **`sample.db`**: SQLite database with employees table.
- **`tmdb_movies.csv`**: Movie data collected from API.
- **`task1_csv.py`**: Reading CSV with Pandas.
- **`task2_json.py`**: Loading JSON data into DataFrame.
- **`task3_sql.py`**: Reading SQL table using SQLite3 and Pandas.
- **`task4_api.py`**: Fetching movie data using Requests.
- **`task5_understand.py`**: Inspecting shape, dtypes, and null counts.
- **`task6_cleaning.py`**: Removing duplicates, renaming columns, and handling missing values.
- **`task7_features.py`**: One-hot encoding and feature/target split.
- **`task8_univariate.py`**: Histplot, countplot, and boxplot.
- **`task9_bivariate.py`**: Scatterplot, correlation heatmap, barplot, and boxplot.
- **`task10_insights.py`**: 5 observations from the data.
- **`main.py`**: Runs all tasks in order.
- **`assignment13.ipynb`**: Complete Jupyter Notebook.

## How to Run

Run all tasks:
```bash
python main.py
```

Or run any task file:
```bash
python task1_csv.py
python task2_json.py
python task3_sql.py
python task4_api.py
python task5_understand.py
python task6_cleaning.py
python task7_features.py
python task8_univariate.py
python task9_bivariate.py
python task10_insights.py
```
