# Streamlit Assignment 8

This project contains simple Streamlit applications built for Assignment 8.

## Files Included

- **`app_basic.py`**: A basic app that asks for a name and displays a greeting message on button click.
- **`app_discount.py`**: A price calculator that takes a price and discount slider to calculate the final price and shows a comparison table.
- **`app_product_form.py`**: A product form built in the sidebar to add and display product details.
- **`app_dashboard.py`**: A mini dashboard displaying monthly sales metric and a simple bar chart.

## How to Run

1. Install Streamlit:
```bash
pip install streamlit
```

2. Run any task:
```bash
streamlit run app_basic.py
streamlit run app_discount.py
streamlit run app_product_form.py
streamlit run app_dashboard.py
```
