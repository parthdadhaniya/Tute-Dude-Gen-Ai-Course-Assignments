# Assignment 15: Core Algorithms, Metrics & Model Behavior

This project covers core ML algorithms, regression & classification metrics, and overfitting/underfitting concepts.

## Files Included

- **`employee_data.csv`**: Dataset for regression and classification.
- **`task1_linear_regression.py`**: Linear regression training and scatter plot.
- **`task2_regression_metrics.py`**: MAE, MSE, and RMSE.
- **`task3_logistic_regression.py`**: Logistic regression classifier.
- **`task4_naive_bayes.py`**: Gaussian Naive Bayes and comparison.
- **`task5_knn.py`**: KNN with k=1, 3, 5, 7.
- **`task6_classification_metrics.py`**: Confusion matrix and classification report.
- **`task7_overfitting_underfitting.py`**: Comparing underfitting vs overfitting models.
- **`task8_bias_variance.py`**: Conceptual answers on bias and variance.
- **`main.py`**: Runs all tasks in order.
- **`assignment15.ipynb`**: Complete Jupyter Notebook.

## How to Run

Run all tasks:
```bash
python main.py
```

Or run any task file:
```bash
python task1_linear_regression.py
python task2_regression_metrics.py
python task3_logistic_regression.py
python task4_naive_bayes.py
python task5_knn.py
python task6_classification_metrics.py
python task7_overfitting_underfitting.py
python task8_bias_variance.py
```
