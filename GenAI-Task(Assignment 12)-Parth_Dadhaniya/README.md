# Assignment 12: Seaborn Visualizations

This folder contains Python scripts and a Jupyter Notebook for Assignment 12 on Seaborn. It uses the student performance dataset (`student_performance.csv`).

## Files Included

- **`task1.py`**: Relational plot using relplot with hue and scatter style.
- **`task2.py`**: Line plot, scatter-style line plot, and faceted line plot by gender.
- **`task3.py`**: Histogram, KDE, rug plot, and combined histplot with KDE.
- **`task4.py`**: Bivariate histogram and bivariate KDE plot.
- **`task5.py`**: Pairplot and correlation heatmap.
- **`task6.py`**: Bar plot, box plot, violin plot, and count plot.
- **`task7.py`**: Regression plot (regplot) and lmplot with hue.
- **`task8.py`**: FacetGrid and multi-plots with relplot, catplot, and displot.
- **`main.py`**: All tasks in a single script.
- **`assignment12.ipynb`**: All tasks in a Jupyter Notebook.

## How to Run

Run all tasks:
```bash
python main.py
```

Or run each task file:
```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
python task6.py
python task7.py
python task8.py
```
